02

Hydroponics AI System

STEAM Research Grant DFRobot Hardware Sponsored
Hardware Schema

An industrial IoT automation platform applying Reinforcement Learning (RL) frameworks to soil-free smart urban farming. This system calculates data modeling vectors across environmental metrics to predict yield values, automate complex chemistry balancing, and preserve power metrics. **Funded by the Ministry of Education, Science and Technology under the STEAM Grant.**

Embedded C/C++ TensorFlow Core PyTorch RL OpenCV Matrix Raspberry Pi Architecture Arduino Drivers ESP32 SoC MQTT Protocol WebSockets FastAPI Flutter UI

🔌 Hardware Engineering & DFRobot Sponsorship Partnership

Following technical business outreach, this system was officially gifted hardware parts by global robotics hardware firm DFRobot. They sponsored precision industrial instrumentation modules (pH, EC probes, automated telemetry actuators) to maintain continuous local real-time edge processing data accuracy.

What I Engineered

  • Programmed the embedded control layer on ESP32 and Raspberry Pi to interface with pH, EC, temperature, and humidity sensors.
  • Implemented sensor data acquisition and actuator control to manage pumps and nutrient dosing mechanisms via MQTT.
  • Developed the backend infrastructure for the computer vision pipeline, enabling image uploads and AI model inference.
  • Developed a FastAPI backend with MQTT and WebSocket support for real-time device monitoring and automation.
  • Integrated LiveKit for real-time video streaming to enable live monitoring of plant growth.
  • Built a Flutter mobile application for monitoring sensor data, live streams, and remote control.
  • Deployed the system on a local edge server to support real-time processing and device communication.
