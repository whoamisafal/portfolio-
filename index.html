Self-Hosted Public Cloud Infrastructure

Bare-Metal Hardware Stack Semester Project Tiffin Backend

How do you avoid expensive public cloud bills while keeping full low-level systems control? I architected, built, and provisioned an independent **bare-metal server node** and configured it to be publicly accessible from the open internet. This custom hardware rig hosted the production data endpoints, security rules, and real-time transaction pipelines for the **Like Tiffin** mobile application ecosystem.

Bare-Metal Linux Architecture Public IP Networking Reverse Proxy Routing Secure SSH Layer Node.js Daemon Processing Hardware System Maintenance

Infrastructure Engineering Steps

  • Assembled the standalone server hardware, managing cooling limits and computing power requirements.
  • Configured core Linux network settings, static IP routers, and network firewalls to allow incoming traffic safely.
  • Set up reverse proxy configurations to manage domain handling and enforce SSL encryption layers.
  • Maintained perfect database and API uptime on raw physical hardware to reliably serve mobile clients under pressure.
