Stack

Embedded C/C++ · TensorFlow Core · PyTorch RL · OpenCV Matrix · ESP32 SoC · Raspberry Pi · Arduino Drivers · MQTT Protocol · WebSockets · FastAPI Backend · Flutter Dashboard · Gymnasium · LiveKit Video Stream

Project 04

AIHPC — High-Performance Computing Cluster

KU Department of AI

In 2025, I led an intensive system orchestration initiative within Kathmandu University's Department of AI to build a dedicated high-performance computing cluster (AIHPC). The project involved configuring Kubernetes containers for scaling distributed worker loads and establishing HAProxy layers to direct load balancing across system networks.

Stack

Kubernetes (K8s) · HAProxy Load Balancing · NVIDIA RTX 3080Ti · Docker Containers · Linux Administration · GPU Cluster Topology

Engineering Post-Mortem: Why It Failed

  • The hardware environment was limited because consumer-grade NVIDIA GeForce RTX 3080Ti GPUs lack hardware-level architecture partitioning (Multi-Instance GPU / MIG)
  • This constraint prevented stable multi-tenant GPU virtualization across the cluster
  • Localized technical team knowledge scaling boundaries further compounded the hardware limitations
  • The project provided deep insight into the practical boundaries between enterprise grid computing systems and consumer accelerator units
